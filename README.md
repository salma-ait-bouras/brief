# Documentation du site web — Élan Fitness

## 1. Présentation du projet

Élan Fitness est un site web vitrine pour une salle de sport située à Casablanca. Il a pour objectif de présenter la salle, ses services et ses programmes sportifs, et de permettre aux visiteurs de découvrir les informations importantes.

## 2. Objectifs du projet

Les principaux objectifs de ce projet sont :
- Créer un site web simple et agréable à consulter.
- Présenter les services de la salle de sport.
- Organiser les informations de manière claire.
- Faciliter la navigation entre les différentes sections.
- Appliquer les connaissances de base en HTML et CSS.

## 3. Technologies utilisées

**HTML5 :** utilisé pour créer la structure du site web et organiser le contenu.

**CSS3 :** utilisé pour mettre en forme le site, modifier les couleurs, gérer les espaces et améliorer la présentation des éléments.

## 4. Structure du site web

Le site contient plusieurs sections principales :

- **Accueil :** présente le nom de la salle, un slogan et un bouton pour découvrir les programmes.
- **À propos :** présente les avantages de la salle de sport.
- **Programmes :** permet aux visiteurs de découvrir les programmes sportifs proposés.
- **Contact :** permet de consulter les informations de contact.

## 5. Les éléments HTML utilisés

Voici quelques balises HTML importantes utilisées pour construire le site :

- `<header>` : représente l'en-tête du site.
- `<nav>` : contient les liens de navigation.
- `<main>` : contient le contenu principal.
- `<section>` : permet de séparer le contenu en différentes parties.
- `<h1>`, `<h2>` et `<h3>` : permettent d'organiser les titres.
- `<p>` : permet d'ajouter des paragraphes.
- `<a>` : permet de créer des liens.
- `<img>` : permet d'afficher des images.
- `<footer>` : représente le pied de page.

## 6. Les principales propriétés CSS utilisées

Le CSS permet de personnaliser l'apparence du site. Parmi les propriétés importantes :

- `color` : modifier la couleur du texte.
- `background-color` : modifier la couleur de l'arrière-plan.
- `font-family` : choisir la police d'écriture.
- `font-size` : modifier la taille du texte.
- `margin` : gérer les espaces extérieurs.
- `padding` : gérer les espaces intérieurs.
- `display` : organiser l'affichage des éléments.
- `width` et `height` : définir la largeur et la hauteur.
- `border-radius` : arrondir les coins des éléments.

## 7. Organisation des fichiers

Le projet peut être organisé de la manière suivante :

- `index.html` : contient la structure de la page web.
- `style.css` : contient les règles CSS utilisées pour le design.
- `images/` : contient les images utilisées dans le site, si elles sont stockées localement.

## 8. Difficultés rencontrées

Pendant la réalisation du projet, certaines difficultés peuvent apparaître, notamment :
- Comprendre le rôle des différentes balises HTML.
- Organiser correctement les sections du site.
- Appliquer les propriétés CSS pour obtenir le design souhaité.
- Gérer les espaces et l'alignement des éléments.
- Vérifier que les liens fonctionnent correctement.

## 9. Conclusion

Ce projet m'a permis de découvrir les bases de la création d'un site web avec HTML et CSS. J'ai appris à structurer une page web, à organiser son contenu et à améliorer son apparence grâce au CSS. Ce travail constitue une première étape dans mon apprentissage du développement web.
